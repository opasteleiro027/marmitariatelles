# Montador de marmita

Fluxo público inspirado no modelo do Google Stitch. Conduz o cliente por
tamanho, base, feijão, proteína, acompanhamentos, adicionais e observação.

As opções gratuitas de base e feijão usam `+` para indicar a ação de selecionar
e `✓` para confirmar a escolha, evitando a impressão de que todas já estão
incluídas.

Nenhum tamanho é selecionado automaticamente. O `✔️` aparece apenas depois do
clique do cliente. Após adicionar uma marmita, o resumo mostra
`CONTINUAR COMPRANDO`; ao clicar, tamanho, ingredientes e observação são
limpos para iniciar uma nova montagem.
