# Campos de localização e endereço

Peça de checkout responsável pelo botão de GPS, consulta por CEP, sugestão de
endereço, identificação automática da área atendida e fallback manual.

O componente nunca bloqueia o preenchimento manual. A permissão só é solicitada
depois do clique em “Usar minha localização”.
Não existe seletor manual de área: cidade e bairro determinam a taxa exibida.
