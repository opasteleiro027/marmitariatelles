# Gestão do estabelecimento

Permite editar os dados públicos e administrar bairros, taxas,
pedidos mínimos e disponibilidade de entrega.

O liga/desliga fica no topo do painel e não é duplicado neste formulário.

Cada bairro pode ser excluído após confirmação explícita. A exclusão afeta
somente a operação futura; os snapshots dos pedidos antigos são preservados.
