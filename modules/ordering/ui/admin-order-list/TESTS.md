# Cenários de teste

- avançar pedido confirmado até preparo e conclusão;
- cancelar pedido e devolver estoque;
- impedir transições inválidas e acesso sem sessão administrativa.
- atualizar o painel ao alterar o sinal protegido;
- tocar apenas para novo pedido depois que o administrador ativar o som;
- não tocar em mudança de status nem quando o som estiver desativado.
