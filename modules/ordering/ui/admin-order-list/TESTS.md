# Cenários de teste

- avançar pedido confirmado até preparo e conclusão;
- cancelar pedido e devolver estoque;
- impedir transições inválidas e acesso sem sessão administrativa;
- refletir os pedidos recebidos pelo servidor;
- imprimir uma comanda térmica completa pelo navegador;
- não possuir responsabilidade pelo monitor ou pelo áudio global.
