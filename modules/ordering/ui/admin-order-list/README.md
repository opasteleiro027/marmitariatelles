# Lista administrativa de pedidos

Exibe os pedidos gravados no PostgreSQL e permite avançar o fluxo operacional
por transições de status validadas no servidor.

Cada pedido oferece uma comanda térmica de 80 mm por meio da janela de
impressão nativa do navegador.

O monitor e o alerta de novos pedidos pertencem ao componente independente
`admin-order-monitor`, montado globalmente no painel.
