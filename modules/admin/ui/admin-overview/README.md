# Visão geral administrativa

Resume o estado operacional, as métricas gerais e o fechamento comercial. É a
única tela que combina dados públicos, pedidos e o controle de ligar/desligar o
site.

O relatório de desempenho é calculado diretamente dos pedidos e oferece filtros
de dia, semana e mês. Ele apresenta faturamento, ticket médio do pedido, gasto
médio por cliente, recompra, clientes mais frequentes, bairros, itens, entregas,
retiradas, cancelamentos e formas de pagamento.

Pedidos cancelados são separados do resultado comercial. Os limites dos
períodos respeitam o fuso `America/Sao_Paulo`, portanto o filtro diário pode ser
usado como fechamento do expediente sem uma ação manual.
